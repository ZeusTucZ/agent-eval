# Code of conduct

agent-eval is a place to build a useful tool together. Everyone taking part, in issues,
discussions, pull requests and reviews, is expected to:

- be respectful and patient, especially with people new to the project or the field;
- criticise ideas and code, never people, and explain the reasons for a suggestion;
- assume good faith, and ask before assuming;
- keep it on topic, and keep personal information (yours or others') out of public threads.

Harassment, insults, discriminatory language, and sharing someone's private information are
not acceptable, and lead to removal of the content and, if repeated, from the project.

To report a problem, contact the maintainer privately through the email on their GitHub
profile, or GitHub's report feature. Reports are kept confidential.
